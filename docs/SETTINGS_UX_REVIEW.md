# 设置与快捷短语体验改进

## 整理后的需求提示词

请优化 DotaPet 从安装后首次启动到日常使用的设置体验。首次启动应自动显示并聚焦 API 设置，用户无需再次点击「AI 设置」就能粘贴密钥。设置窗口应适配 Windows 高 DPI 和小屏幕，主要操作应在首屏可见。

语音聊天和文字 / 截图翻译按功能组织，明确各自使用的服务商及共享关系：千问共用一份 API 密钥和地区配置，两种功能使用各自的模型。避免在高级设置里重复选择翻译服务商。切换功能或服务商保留本窗口内的输入，保存翻译配置不得覆盖语音服务商、模型或音色；不涉及当前语音凭据的翻译修改不得打断语音连接。保存失败、取消导入或删除失败时保留输入，成功保存后清空已提交的明文密钥。

快捷短语面板已存在于桌宠右键菜单、托盘和 F6，无需重建。增加设置页入口，清晰标注中文 / 英文复制操作及 DOTA 2 粘贴步骤。已有双语短语无需 API 密钥即可复制；AI 补全使用当前选择的翻译服务商。保存后保持面板打开，便于连续复制；小窗口下允许滚动短语，保持保存和关闭按钮可见。

按功能拆分提交，补充有意义的回归验证，推送前进行对抗式审查并修复发现的问题。

## 推送前对抗式审查

本次采用代码审查、失败路径回归测试和真实 Electron 渲染检查，未使用独立审查代理。

| 场景 | 发现与处理 | 验证 |
| --- | --- | --- |
| 首次启动的事件顺序 | 桌宠晚于设置出现时会抢焦点；设置缺少显示事件兜底 | 窗口展示兜底测试；首次设置 Electron 测试 |
| 关闭窗口后延迟回调 | 使用捕获的窗口实例，关闭时取消定时器；迟到的显示事件不再次抢焦点 | 已销毁窗口和迟到事件测试 |
| Windows 缩放与小屏 | 初始尺寸及最小尺寸受可用桌面区域约束 | 非零屏幕原点和 600×580 可用区域测试；620 宽布局检查 |
| 翻译保存影响语音 | 原来的保存操作会覆盖所选语音服务商；现分别保存功能选择，保护千问语音模型和音色 | 加密设置重载测试；凭据变更判断测试 |
| 密钥串到其他服务商 | 草稿按服务商隔离；千问在两个功能间共享；Google 两种语音模式仍保留独立凭据 | 现有隔离测试、共享草稿测试及加密存储测试 |
| 高级音色草稿 | 简化音色列表重新渲染后缺少草稿音色，真实 select 会变空；恢复草稿前补充选项 | 单元回归和真实 Electron 页签往返测试 |
| 保存及导入失败 | 保存失败保留输入；取消导入及删除失败也保留输入 | 失败及取消路径回归 |
| 短语保存与连续复制 | 原面板保存后延迟关闭；已移除自动关闭 | 实际 IPC 保存、等待超过原关闭延迟、中文及英文复制测试 |
| 短语窗口缩小 | 行内复制按钮可换行；底部操作固定可见 | 620×520 Electron 布局检查及截图 |
| 测试污染真实数据 | 使用隔离用户目录；复制测试记录文本而不写入系统剪贴板 | Electron smoke 流程 |

验证命令：`npm test`、`npm run smoke`、`git diff --check`。

集成测试不调用付费云端接口；实际账户权限、余额、视觉模型访问和游戏全屏下的窗口层级仍需在对应环境体验。
