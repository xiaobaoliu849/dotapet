# 刀塔宠物 · Windows 体验版 0.2.4

陪你开黑的 DOTA2 桌面宠物，支持英雄与信使陪伴、AI 语音对话、双语快捷短语和对局聊天翻译。

下载本页的 `DotaPet-Setup-0.2.4.exe` 安装，已安装旧版本的用户可直接在「设置中心 → 关于与更新」中无感检查更新与一键升级；`SHA256SUMS.txt` 提供安装包校验值。

## 0.2.4 更新内容

- **强化定制角色人设沉浸感**：当召唤师为角色设置了特定人物、身份、态度或说话风格时，AI 严格代入该角色身份与第一人称口吻进行互动，坚决防止泛化的“桌面伴侣/助手”套话自称。
- **通话中人设热重载支持**：在实时语音通话中切换或调整人设时，豆包 (Doubao) 等双工引擎安全平滑重连并即时应用新设定，并在状态中广播 `restarting` 标识。
- **应用内热更新升级**：支持已安装客户端在设置中心一键检测并更新至 0.2.4。

## 常用快捷键

- `Alt+S`：快速打开 / 呼出设置中心
- `Alt+Shift+Q`：彻底退出桌面宠物
- `Alt+Q`：开关麦克风 / 开始与结束语音对话
- `Alt+T`：抓取或读取游戏聊天截图进行翻译
- `F8`：翻译聊天输入框内容（中文翻为英文）
- `F6`：呼出游戏双语快捷短语面板
- 右键桌宠或点击托盘图标：打开操作菜单与设置中心

## 安装与升级说明

- **已安装用户**：打开「设置中心 → 关于与更新」点击「检查更新」，即可直接自动下载并一键更新重启。
- **全新安装**：下载 `DotaPet-Setup-0.2.4.exe` 并按向导安装即可。
- 同一 Windows 用户下，原有数据目录、API 密钥和外观配置会自动继承保留。
