# 刀塔宠物 · Windows 体验版 0.2.5

陪你开黑的 DOTA2 桌面宠物，支持英雄与信使陪伴、AI 语音对话、双语快捷短语、对局黑话秒翻与游戏战斗趣味互动彩蛋。

下载本页的 `DotaPet-Setup-0.2.5.exe` 安装，已安装旧版本的用户可直接在「设置中心 → 关于与更新」中无感检查更新与一键升级；`SHA256SUMS.txt` 提供安装包校验值。

## 0.2.5 更新内容

### 1. DOTA 黑话秒翻词典（中 / 英 / 俄秒翻）
- **专有战术与俚语精准翻译**：内置 `rosh`（肉山）、`bkb`（黑皇杖）、`ss`（大招/消失）、`smoke`（开雾）、`buyback`（买活）、`rax`（兵营）等海量 DOTA 经典词库，彻底告别把“smoke（开雾）”翻译成“抽烟”的尴尬机翻。
- **混合战术缩写智能补全**：针对玩家常用的多词组短句（如 `smoke rosh`、`bkb tp`、`no bb end`）提供上下文战术联想与一键快捷发送建议。

### 2. DOTA 战况趣味互动彩蛋（Fun 驱动）
- **❓ 金色公屏问号嘲讽粒子**：
  - **极限残血锁血逃生**：生命值 `< 10%` 被追杀并成功拉扯回血脱险，宠物自动激发展现 6 颗金色发光 `?` 漂浮粒子与绿光治愈星火，附带专属嘲讽语音与气泡。
  - **点击互动**：无论在信使还是英雄模式下，单击状态胶囊或双击立绘，均可喷射金色问号粒子进行互动。
- **👑 三圣剑「BKB 天神下凡」巨大化金身**：
  - 英雄背包主栏同时装备 3 把及以上圣剑（或在桌面底栏连续点击 3 次 `⚔️` 喂食圣剑），立绘触发 **1.25 倍放大、双层金色流动护盾、喷射金色粒子与天神下凡霸气语音**。
- **🪦 连死毒舌破防吐槽（防上头提醒）**：
  - 连续阵亡 $\ge 2$ 次（期间无击杀入账）时，状态栏与气泡自动切换为幽默毒舌老哥台词，伴随幽灵与问号粒子，温柔提醒召唤师冷静心态、停止冲脸。
- **📜 10 分钟出门忘带 TP 贴心警报**：
  - 比赛 10 分钟后满血且背包内无回城卷轴（TP）时，自动弹出气泡与语音提醒，防止团战支援脱节。
- **英雄伴侣与信使全面打通**：
  - 上述所有趣味特效、粒子动画与底栏道具互动均已全面适配 **127 位 DOTA 英雄**、内置信使以及自定义上传角色。

### 3. 稳定性与体验优化
- **修复翻译 HUD 气泡与桌宠状态互斥问题**：确保战斗高光事件不被默认待命动作意外冲掉。
- **优化多桌面与隐藏窗口识别**：提升 Windows 各种显示模式下的窗口呈现稳定性。

## 常用快捷键

- `Alt+S`：快速打开 / 呼出设置中心
- `Alt+Shift+Q`：彻底退出桌面宠物
- `Alt+Q`：开关麦克风 / 开始与结束语音对话
- `Alt+T`：抓取或读取游戏聊天截图进行翻译
- `F8`：翻译聊天输入框内容（中文翻为英文）
- `F6`：呼出游戏双语快捷短语面板
- 右键桌宠或点击托盘图标：打开操作菜单与设置中心

## 安装与升级说明

- **已安装用户**：打开「设置中心 → 关于与更新」点击「检查更新」，即可直接自动下载并一键更新重启。
- **全新安装**：下载 `DotaPet-Setup-0.2.5.exe` 并按向导安装即可。
- 同一 Windows 用户下，原有数据目录、API 密钥和外观配置会自动继承保留。
