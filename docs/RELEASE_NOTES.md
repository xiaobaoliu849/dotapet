# 刀塔宠物 · Windows 体验版 0.2.2

陪你开黑的 DOTA2 桌面宠物，支持英雄与信使陪伴、AI 语音对话、双语快捷短语和对局聊天翻译。

下载本页的 `DotaPet-Setup-0.2.2.exe` 安装，已安装旧版本的用户可直接在「设置中心 → 关于与更新」中无感检查更新与一键升级；`SHA256SUMS.txt` 提供安装包校验值。

## 0.2.2 更新内容

- **补充快捷键提示（Tooltips）**：顶部工具栏退出按钮悬停提示新增 `(Alt+Shift+Q)`，底部快捷栏设置中心按钮悬停提示新增 `(Alt+S)`。
- **系统托盘与右键菜单提示完善**：系统托盘菜单与右键菜单项全面补充快捷键提示（`⚙️ 设置中心 (Alt+S)`、`👋 退出伴侣 (Alt+Shift+Q)`）。
- **应用内热更新升级**：支持已安装客户端在设置中心一键检测并更新至 0.2.2。

## 常用快捷键

- `Alt+S`：快速打开 / 呼出设置中心
- `Alt+Shift+Q`：彻底退出桌面宠物
- `Alt+Q`：开关麦克风 / 开始与结束语音对话
- `Alt+T`：抓取或读取游戏聊天截图进行翻译
- `F8`：翻译聊天输入框内容（中文翻为英文）
- `F6`：呼出游戏双语快捷短语面板
- 右键桌宠或点击托盘图标：打开操作菜单与设置中心

## 安装与升级说明

- **已安装用户**：打开「设置中心 → 关于与更新」点击「检查更新」，即可直接自动下载并一键更新重启。
- **全新安装**：下载 `DotaPet-Setup-0.2.2.exe` 并按向导安装即可。
- 同一 Windows 用户下，原有数据目录、API 密钥和外观配置会自动继承保留。
