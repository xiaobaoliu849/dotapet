# 刀塔宠物 · Windows 体验版 0.2.1

陪你开黑的 DOTA2 桌面宠物，支持英雄与信使陪伴、AI 语音对话、双语快捷短语和对局聊天翻译。

下载本页的 `DotaPet-Setup-0.2.1.exe` 安装，已安装 0.2.0 的用户可直接在「设置中心 → 关于与更新」中无感检查更新与一键升级；`SHA256SUMS.txt` 提供安装包校验值。

## 0.2.1 更新内容

- **新增快捷键快速打开设置中心**：默认支持 `Alt+S` 随时呼出设置中心，右键桌宠菜单同步增加对应快捷键提示；支持在「设置中心 → 快捷键与帮助」中自定义更换或禁用。
- **新增快捷键完全退出应用**：默认支持 `Alt+Shift+Q` 彻底关闭并退出桌面宠物，右键菜单同步提示；支持在设置中心自定义配置。
- **全局快捷键列表扩充**：快捷键配置与多语言翻译全面适配简体中文、English、Русский、Українська。
- **应用内热更新体验**：支持已安装 0.2.0 的用户在设置中心自动发现并一键更新到 0.2.1，完整保留所有 API 密钥、形象配置与自定义伙伴数据。

## 常用快捷键

- `Alt+S`：快速打开 / 呼出设置中心
- `Alt+Shift+Q`：彻底退出桌面宠物
- `Alt+Q`：开关麦克风 / 开始与结束语音对话
- `Alt+T`：抓取或读取游戏聊天截图进行翻译
- `F8`：翻译聊天输入框内容（中文翻为英文）
- `F6`：呼出游戏双语快捷短语面板
- 右键桌宠或点击托盘图标：打开操作菜单与设置中心

## 安装与升级说明

- **已安装 0.2.0 用户**：打开「设置中心 → 关于与更新」点击「检查更新」，即可直接自动下载并一键更新重启。
- **全新安装**：下载 `DotaPet-Setup-0.2.1.exe` 并按向导安装即可。
- 同一 Windows 用户下，原有数据目录、API 密钥和外观配置会自动继承保留。
