# 刀塔宠物 · Windows 早期体验版

桌面陪伴、AI 语音与对局聊天翻译。下载本页的 `DotaPet-Setup-<版本>.exe` 安装；`SHA256SUMS.txt` 提供安装包校验值。

## 上手

- 翻译：设置 → 翻译文字 / 截图 → 千问或 DeepSeek → 填密钥并测试；`Win+Shift+S` 框选聊天，再按 `Alt+T`。
- 语音：设置 → 语音对话 → 千问或豆包 → 测试并连接，再按 `Alt+Q` 开关麦克风。
- F8 翻译自己的聊天输入，F6 打开快捷短语。

密钥由用户提供并加密保存在本机。截图和语音会在使用相应功能时发送给所选服务商，按其规则计费。

## 更新与当前限制

0.2.0 增加应用内更新：启动后及每 4 小时检查正式发布版本；托盘 → 检查更新 →「更新并重启」即可下载、校验、安装并重新打开桌宠。关闭更新窗口可稍后安装。API Key、音色和自定义形象继续保留。

旧版本需退出程序并手动安装一次 0.2.0，之后可在应用内更新。保留同一 Windows 用户，原 VoiceSpirit 体验版数据目录继续沿用。

这是一份未签名的 Windows 体验版；没有持续自动 OCR。真实云端识别质量、响应速度和游戏全屏兼容尚需实际验证。自动检查覆盖回归测试及隔离的启动、设置和更新交互流程，不代表已完成真实游戏、云端与实际覆盖安装验收。
