# 刀塔宠物 · Windows 早期体验版 0.2.0

陪你开黑的 DOTA2 桌面宠物，支持英雄与信使陪伴、AI 语音对话、双语快捷短语和对局聊天翻译。

下载本页的 `DotaPet-Setup-0.2.0.exe` 安装；`SHA256SUMS.txt` 提供安装包校验值。

## 0.2.0 主要更新

- **应用内自动更新**：启动后及每 4 小时检查正式发布版本；托盘 / 设置中心随时检查更新，点击「更新并重启」即可自动下载校验并覆盖安装，保留全部 API Key、音色和自定义形象。
- **全新集中式设置中心**：侧边栏整合语音与翻译、形象与背景、快捷短语、快捷键与帮助、关于与更新；支持 Ctrl+Tab 快捷切换与侧边栏折叠。
- **多语言界面**：完整支持简体中文、English、Русский、Українська，标题栏即可随心切换。
- **局内一键聊天翻译**：对局中按 `Alt+T` 直接抓取 DOTA 2 聊天区域翻译（也支持 `Win+Shift+S` 框选截图后按 `Alt+T`），`F8` 翻译自己的聊天输入，`F6` 打开快捷短语面板。
- **个性化角色与自定义伙伴**：支持创建专属自定义伙伴形象，并可编写每个伙伴的角色性格（Personality）与音色，在语音对话中自然代入。
- **API 密钥统一管理**：每家服务的密钥只需保存一次，千问、Google、DeepSeek 等自动跨功能共用；按 Alt+Q 开始计费对话，再按一次即可断开。

## 常用快捷键

- `Alt+Q`：开关麦克风 / 开始与结束语音对话
- `Alt+T`：抓取或读取游戏聊天截图进行翻译
- `F8`：翻译聊天输入框内容（中文翻为英文）
- `F6`：呼出游戏双语快捷短语面板
- 右键桌宠或点击托盘图标：打开设置中心

密钥由用户提供并加密保存在本机 Windows 凭证中。截图和语音仅在使用相应功能时发送给所选服务商，按其规则计费。

## 安装与升级说明

- **全新安装**：下载 `DotaPet-Setup-0.2.0.exe` 并按向导安装即可。
- **从旧版本（0.1.x）升级**：需先退出正在运行的桌宠，手动运行一次 `DotaPet-Setup-0.2.0.exe` 覆盖安装；0.2.0 安装后，后续版本即可在应用内无感更新。
- 同一 Windows 用户下，原 VoiceSpirit 体验版及 0.1.x 的数据目录和配置会自动继承保留。
