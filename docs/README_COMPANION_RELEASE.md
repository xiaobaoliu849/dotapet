# 刀塔宠物 · Windows 体验版 0.2.0（本地构建）

## 安装与第一次使用

1. 从 GitHub Releases 下载并双击 `DotaPet-Setup-0.1.2.exe`。
2. 选择安装目录，完成后打开桌面快捷方式。使用者不需要安装 Node.js。
3. 首次打开直接出现配置页：千问、豆包、Gemini、Cartesia 四张卡片全部显示。选择服务商、粘贴密钥、点击「保存并开始聊天」即可。
4. 如果只想要桌面陪伴，点击「先让它陪着我，稍后设置」即可。关掉配置窗口也会记住这个选择，之后启动不会反复弹出。

当前 GitHub 已发布安装包为 0.1.2；0.2.0 的本地构建位于 `release/DotaPet-Setup-0.2.0.exe`。

下方截图展示当前 0.2.0 源码界面，与已发布的 0.1.2 安装包可能不同。

![当前设置中心：语音与翻译](images/welcome.png)

随时可以右键宠物或任务栏里的金角信使图标，选择「设置中心」，在侧边栏打开「快捷键与帮助」。首次设置关闭后，宠物会提示一次右键菜单和常用快捷键。找不到宠物时，双击托盘图标找回；任务栏右下角的隐藏图标区域也可能收纳它。

## 语音怎么开启

- 在设置的「更多设置」中点击「检查麦克风」，说一句话，看音量条变化。它只在本机检查音量，不保存、不上传、不回放；检查结束、切换服务商或关闭页面都会关闭麦克风。
- 无设备：连接耳机或麦克风，并在 Windows 声音设置中选择默认输入设备。
- 权限关闭：点击「打开 Windows 麦克风设置」，允许桌面应用访问麦克风。
- 设置只有一页：上面是「语音聊天」，下面是「文字 / 截图翻译」。选择千问、豆包、Gemini 或 Cartesia，粘贴自己的 API Key，点击「保存并开始聊天」即可保存并连接，不需要单独测试。没有密钥时可点输入框旁的「获取密钥」。Cartesia 还需要 DeepSeek 密钥。
- 每家服务的密钥只需保存一次：千问密钥同时用于语音和翻译；Gemini 聊天与实时语音翻译共用 Google 密钥；Cartesia 的 DeepSeek 密钥也用于 DeepSeek 翻译。已保存的密钥旁有「移除」，点两次确认后会从所有用到它的功能中移除。
- 每家服务默认已选好声音，通常不需要修改；可在主界面切换三种常用音色，或到「更多设置」选择全部音色。之前保存的其他音色也会继续显示。Gemini 的实时语音翻译位于其「更多设置」中，与 Gemini 聊天共用同一个密钥。
- 连接成功后，回到桌宠点击麦克风或按 `Alt+Q` 开始讲话，再点一次或按同一个快捷键关闭。

连接成功后点击「完成，回到桌宠」，再按语音按钮开始对话。「更多设置」中仍可单独测试语音，麦克风检查也可在遇到声音问题时使用。AI 需要联网，实际用量按服务商规则计费。密钥由 Windows 本机加密保存，不包含在安装包中。

## 看懂队友聊天

![文字与截图翻译设置](images/translation-settings.png)

在设置页的「文字 / 截图翻译」中选千问或 DeepSeek。若语音已经用了同一家的密钥，翻译会直接显示「已就绪」；否则粘贴密钥并点击「保存并启用翻译」。这个操作会测试文字模型，不代表截图识别已经实测通过；视觉模型权限和实际识别结果需用截图确认。

- **队友聊天截图**：按 `Win+Shift+S`，只框选游戏聊天区域；截图进入剪贴板后，按 `Alt+T`，在桌宠浮层看中文结果。程序不会向游戏输入或发送消息，也不会把截图替换为文字。
- **已有文字**：复制文字，按 `Alt+T`。中文成功译成英文时，英文会写入剪贴板，方便手动粘贴。
- **自己向队友发消息**：打开 DOTA2 聊天输入框，输入中文，按 `F8` 翻成英文，检查结果后自己按 Enter 发送。F8 不读取其他玩家的聊天历史。

翻译无需连接语音或开启麦克风。截图会上传到你选择的服务商；只框选聊天区域可减少画面噪声与上传体积。千问截图使用 `qwen3-vl-flash`，DeepSeek 使用 `deepseek-flash`，关闭推理过程以减少等待。旧配置中的 `deepseek-chat` 会迁移为 `deepseek-flash`，保留原密钥。

选择千问时，同一百炼密钥可以用于文字、截图和语音，但相应模型需在所属地区和工作空间可用。「更多设置」中的地区应与密钥一致；有独立工作空间的账户填写工作空间 ID。DeepSeek 在本程序中用于文字与图片，不用于实时语音对话。

文字云翻译失败时可使用有限的本地 DOTA2 术语词表；截图失败会显示重试提示，不会凭空生成译文或自动调用另一家服务。四个语音服务商直接展示，使用 Gemini 或 Cartesia 时需要具备对应的账户与网络条件。

Windows 截图与桌宠浮层需在实际游戏显示模式下验证；建议先在无边框窗口中尝试。独占全屏的截图、前台切换和浮层行为可能不同。当前没有持续自动 OCR，也没有读取游戏进程内存或注入 DLL。

完整的国内服务选择与自动聊天识别路线见 [国内翻译与聊天识别计划](COMPANION_CHINA_TRANSLATION_PLAN.md)。

## 更新与数据

先从宠物或托盘菜单退出旧版，再双击新版安装包覆盖安装即可。同一 Windows 用户下，密钥、自定义形象与短语仍存放在用户数据目录：`%APPDATA%\dota2-voicespirit-companion`。

安装包与开发版沿用相同应用标识和数据目录。卸载默认保留个人设置，重新安装可继续使用；卸载界面中若主动选择删除应用数据，会清除设置。迁移到另一台电脑时，需要重新填写密钥，因为加密与原 Windows 用户相关。

当前体验版未做代码签名。首次运行可能出现 Windows 发布者提示；正式发布前需要配置签名证书。

0.2.0 起可在应用内更新；现在入口是设置中心的「关于与更新」页，有新版本时托盘也会出现「更新到 vX」；发现新版后点击「更新并重启」，会下载并校验更新包、覆盖安装、自动重新打开桌宠。启动后及每 4 小时自动检查 GitHub 正式发布版本，有更新时提供通知和托盘入口；仅检查不下载。关闭设置中心或选择稍后重启，会继续下载但不自动安装，完成后可点击「安装并重启」。普通退出也不会强制安装。

密钥、音色和形象设置继续保留。旧版本需先手动安装一次 0.2.0，之后才能使用应用内更新。GitHub 网络不可用时可重试或打开发布页手动下载。

## 开发与验收

从仓库根目录运行 `npm run dist` 生成安装包。输出位于 `release/`。

在仓库根目录运行：

```powershell
npm test
npm run test:onboarding
npm run smoke
node scripts/smoke-desktop.mjs release/win-unpacked/DotaPet.exe
npm run test:update-download
npm run verify:installer -- -Baseline "你保留的旧安装包.exe"
```

`verify:installer` 需要显式提供旧安装包路径，并先构建当前安装包。它在临时目录中验证旧版安装、新版覆盖、快捷方式、加密的模拟密钥和自定义形象，以及卸载。它会创建实际 Windows 安装登记和快捷方式，并在结束时卸载测试副本；若已有安装或同名快捷方式，会拒绝运行。应在干净 Windows 账户或 Sandbox 中执行，不对真实用户的安装进行验收。

麦克风自动验收使用 Chromium 模拟音频设备，不访问真实麦克风；真实耳机、麦克风权限与云端 API 需在使用界面中验证。

回归测试覆盖更新状态、重复点击、校验失败和推迟重启；源码与打包程序的桌面冒烟测试使用模拟发布数据验证真实窗口及 IPC。`test:update-download` 用本机回环服务器和隔离缓存下载真实安装包，验证发布元数据、SHA512、错误校验值拒绝，不执行安装。该机器已有旧版安装，不执行真实覆盖安装与卸载。真实云端截图识别、延迟和游戏全屏兼容也尚未实测。

独立仓库从 0.1.0 重新编号，原本机试制版本的 1.x 不表示正式稳定版。DotaPet 保留原安装标识和用户数据路径，但品牌变化及从 1.x 迁移到 0.x 的实际安装行为仍需在干净账户中验证。退出旧版后手动安装；自动更新不降级到较低版本。

发布流水线会上传安装包、`latest.yml`、`.blockmap` 和 SHA256 校验值；`v0.*` 标签触发的发布从 0.2.0 起作为正式发布渠道（仍属早期体验版）。开发运行 `npm start` 不会检查或安装更新。本地构建不等于已发布，需将新版及元数据发布到 GitHub 后，其他安装版才能收到更新。

图标源文件是 `src/renderer/assets/app-icon.svg`。修改后运行 `npm run build:icons`，同步生成六种尺寸的 ICO 和 PNG，再打包。
