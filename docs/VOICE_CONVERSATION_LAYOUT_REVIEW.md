# 语音对话布局与推送前审查

日期：2026-10-09。

连接成功后展开对话布局：头像移至工具栏下方，缩小为原来的 68%；下方转写区使用固定高度，内部滚动。窗口大小与桌面位置不变。关麦或断开连接保留记录，手动收起恢复原头像；新一轮连接、主动开启麦克风或手动打开记录可以再次展开。

转写、翻译卡共用下方阅读区。翻译打开时暂时隐藏转写，关闭后恢复。短暂操作提示使用头像左侧空间。萌宠动画和状态标签仍可更新，自动台词不覆盖正在阅读的对话。放大的自定义形象在头像区域内裁切。

## 对抗性审查

本次由实现者对最终差异进行反向检查，并使用真实 Electron 页面验证以下情形：

| 情形 | 结果 |
| --- | --- |
| 连接尚未成功、重复状态与持续转写 | 连接中不进入对话布局；每个转写片段不重复测量布局 |
| 手动收起后收到迟到回复 | 记录继续保存，不强制重新展开 |
| 关麦、断开连接、离线打开历史 | 保留记录，离线打开时仍为头像留出位置 |
| 向上阅读时收到新回复 | 不抢走滚动位置，提供回到最新按钮 |
| 收起期间消息超过 40 条、旧消息被清理 | 再打开时通过仍存在的消息锚点恢复阅读位置；锚点已经被清理则显示最早保留的内容 |
| 空记录、长回复和长翻译 | 阅读区尺寸固定，文本在内部滚动，不覆盖头像和操作按钮 |
| 游戏状态栏、标准 / 精简 / 迷你尺寸 | 用根容器未缩放的坐标计算位置，区域互不遮挡 |
| 萌宠动画台词、旧台词计时器 | 对话中不插入台词卡；旧计时器不能关闭新翻译卡 |
| 键盘关闭、减少动态效果偏好 | 关闭后焦点返回转写按钮；减少动态效果时取消头像移动过渡 |
| 短暂操作提示 | 位于头像侧边，不挡转写与按钮 |

审查未发现剩余阻断项。`npm test` 171 项通过；`npm run smoke` 通过，新增 `conversation` 验收覆盖布局、历史、麦克风开关、离线记录、缩放、游戏栏、萌宠与翻译冲突，并保存头像和萌宠模式截图。

验收通过生产 IPC 驱动真实页面，使用模拟麦克风与本地内容，没有调用云端服务。隐藏的验收窗口禁用了 CSS 动画以检查最终几何位置，并主动捕获一帧以执行 ResizeObserver；实际应用保留约 300 毫秒的头像移动动画。
